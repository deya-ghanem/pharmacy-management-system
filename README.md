# Pharmacy Management System

## Project Description

The Pharmacy Management System is a software system designed to help pharmacies manage their daily operations through one organized and user-friendly application.

The system aims to make pharmacy operations faster and more efficient, especially when searching for medicines, checking their availability, completing sales, and managing inventory.

## Objective

The main objective of this project is to develop a fast, organized, and easy-to-use system that brings the main pharmacy operations together in one application.

The system will help pharmacists and pharmacy employees manage medicines, inventory, sales, purchases, suppliers, customers or patients, users, and reports.

## Target Users

The main target users are:

- Pharmacists
- Pharmacy Employees
- Administrators

Each user type will have different permissions according to their responsibilities.

## Planned Technologies

Possible technologies include:

- Frontend: HTML, CSS, JavaScript / modern web framework
- Backend: To be determined
- Database: PostgreSQL
- Version Control: Git and GitHub

The final technologies may change during the development process.
